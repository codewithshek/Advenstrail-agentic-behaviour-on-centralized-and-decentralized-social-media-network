Chapter I — Observation 01 / 05

An account is a biography. A set of accounts is a shape.

Inputs, not assumptions

trace

Handles · threads · exports Fig. 1

01 · The inputThree ways into a case

Nothing is fetched silently. You supply the evidence.

A single post proves very little. A hundred posts published inside the same ninety seconds, by accounts that share followers, vocabulary and a link, prove rather more. The work starts with whatever the case offers.

The console has no platform credentials, so handle lookups run on a deterministic simulation and say so in the report. Real evidence arrives through the other two routes: a thread pasted line by line, or an export of activity from a platform, a federated instance, or an agent-to-agent relay.

Every input is normalised into the same contract — accounts, directed edges, posts — so the text model and the graph model read the same case, and the interface can show you exactly where they disagree.

02 · Text intelligenceExact trigger spans

The payload is evidence. Treat it that way.

A prompt injection is not a rude sentence. It is an instruction aimed at whatever model reads next — a support bot, a summariser, an agent holding tool access. The sentence that carries it is often polite, short and buried three replies down.

A weighted DeBERTa-v3 classifier scores each post on its own, then the interface returns the exact character spans that moved the score. Spans are escaped before they reach the DOM, so a payload that tries to inject markup is displayed as evidence rather than executed as layout.

Federated and agent-to-agent traffic adds a second vocabulary: discovery spoofs, token hijacks, relay directives. Those tokens are surfaced as protocol markers rather than folded into a single opaque risk number.

03 · Behavioural graphSignals and their limits

The label comes from behaviour. Communities only help you look.

Repetition alone is cheap. What raises the cost of coincidence is agreement across independent signals: accounts posting inside the same window, returning each other's amplification, borrowing the same sentences, and pointing at the same few hubs.

Each signal is bounded and explainable. Synchrony is measured against an independence expectation rather than a raw count. Reciprocity asks whether a directed interaction comes back. Duplication is checked within an account and across accounts.

Louvain communities are drawn on the graph so an analyst can navigate a dense network. They do not decide the label; a visually tidy cluster can be entirely organic.

Chapter IV — Architecture 04 / 05

A hub and a bridge fail differently. The perimeter decides which.

Centralized / federated

topology

Entropy · cross-instance ratio · bridges Fig. 4

04 · ArchitectureSame model, different perimeter

One evidence model. Two very different perimeters.

On a centralized platform, power collects at the hub. A campaign can buy reach by attaching itself to one account with an audience, then flooding a hashtag or a reply column until the recommendation system takes over.

On a federated network, there is no single hub to capture. The interesting node becomes the bridge: the account or relay that carries an edge from one instance to another, and therefore carries moderation blind spots with it. Agent-to-agent discovery adds a third perimeter, where a forged capability token is the exploit.

The console classifies the architecture first, then reads the signals in that context. Instance entropy, cross-instance edge ratio, in-degree Gini and bridge centrality mean different things at each perimeter.

Centralized star · hub

One namespace, one ranking surface, one point of capture.

  • Hashtag flood Synchronised volume aimed at a trending surface.
  • Retweet ring Reciprocal amplification inside a closed set.
  • Reply hijack Borrowing an influencer hub's comment column.
  • Signatures H ≈ 0 · cross-instance ≈ 0 · no boundary bridges.

Federated multi-cluster

Many namespaces, uneven moderation, and edges that cross the seams.

  • Sybil bridge Accounts that straddle instances to move a campaign.
  • Defederation evasion Re-forming across instances after a block.
  • Protocol spoof Forged A2A discovery or hijacked MCP tokens.
  • Signatures H > 0.4 · cross-instance > 10% · bridge centrality ≥ 0.25.
