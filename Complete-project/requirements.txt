#  Python: 3.10 / 3.11 STRONGLY recommended. Use 3.11 if you have a choice.
#
#  Verified on this machine: `py -0p` reports 3.14 and 3.13 installed.
#    * 3.14 will NOT work — torch has no wheels for it at any version.
#    * 3.13 works only with torch>=2.6, and `sentencepiece` (required by the
#      DeBERTa-v3 tokenizer) has no 3.13 wheel on Windows, so pip falls back to
#      a source build that needs Visual C++ Build Tools. If notebook 02 fails on
#      `AutoTokenizer.from_pretrained`, this is why.
#    * 3.11 has binary wheels for every pin below, including sentencepiece and
#      the compiled PyG extras.
#
#  Install 3.11 alongside what you have and build the venv against it:
#      winget install Python.Python.3.11
#      py -3.11 -m venv .venv
#      .venv\Scripts\activate
#
#  INSTALL ORDER MATTERS — PyTorch Geometric compiles against the exact torch
#  build, so install torch first, then the PyG extras from the matching wheel
#  index. See `README.md` and `docs/GENERALIZATION_RUNBOOK.md` for commands.
#
#      python -m venv .venv && source .venv/bin/activate     # Win: .venv\Scripts\activate
#      pip install --upgrade pip wheel setuptools
#      pip install torch==2.3.1 --index-url https://download.pytorch.org/whl/cpu
#      pip install -r requirements.txt
#
#  GPU users: swap the torch index-url for cu121 and (optionally) install the
#  compiled PyG extras:
#      pip install torch-scatter torch-sparse \
#          -f https://data.pyg.org/whl/torch-2.3.1+cu121.html
#  They are OPTIONAL — every GNN layer used in notebook 03 falls back to pure
#  torch scatter ops when the compiled extensions are absent.
